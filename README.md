# Wayfind releases

Installable tarballs of the Wayfind packages, built from `main` with `pnpm release:pack`.
Install them straight from GitHub, no npm registry needed:

```bash
npm install https://raw.githubusercontent.com/xuewei-j/wayfind-design-system/releases/0.1.0/wayfind-react-0.1.0.tgz
```

`@wayfind/react` pulls in the matching `@wayfind/tokens` tarball on its own.
