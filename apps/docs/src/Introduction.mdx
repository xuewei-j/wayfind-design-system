# Wayfind

**A small design system for humans and AI agents.**

More and more UI is written by AI agents — in Cursor, Claude Code, ChatGPT. They write fast, but they don't know your design
system: they hard-code `#3b82f6`, invent a `variant="tertiary"`, and leave fields without labels. Wayfind is an experiment
in giving a design system a second audience. Everything a designer documents for people is also served, through an
[MCP](https://modelcontextprotocol.io) server, to the agents writing the code.

## What's inside

- **`@wayfind/tokens`** — design tokens in the W3C DTCG format. One JSON file becomes CSS variables, a typed JS API, and an
  accessibility contract that fails the build if a color pair drops below WCAG AA.
- **`@wayfind/react`** — eight accessible React components, plus a **registry**: machine-readable docs for each one (props,
  do/don't, accessibility notes, examples).
- **`@wayfind/mcp`** — an MCP server that hands agents the registry and tokens, with a `check_styles` linter that catches
  and fixes off-system code.
- **`@wayfind/docs`** — this Storybook. Component docs pages are generated from the same registry entries the agents read.

## One source, two audiences

```
tokens.json ──┬──► tokens.css ───────────────► components ──► Storybook (people)
              └──► token API ──┐
component registry ────────────┴──► MCP server ──► Claude / Cursor / ChatGPT (agents)
```

Tests keep the two in sync: every prop must be documented, every color token a component's CSS uses must appear in its
registry entry, and the component library must pass its own linter.

## Where to start

- **Foundations → Colors → Contrast contract** — why only Brand / Primary `#BA4300` (5.40:1) carries white text, and the lighter oranges don't.
- **Patterns → Exhibition booking** — a full page built only from the system. Toggle dark mode in the toolbar.
- **Agents → Style checker** — paste AI-generated code and watch it get linted and fixed.

## The brand

Color and type follow the product design system: Brand / Primary `#BA4300`, text grays `#0D0D0D` / `#5D5D5D` /
`#8F8F8F`, and SF Pro at 400 and 600 on a 12–36px ramp. Corners stay nearly square, like gallery wall labels — a nod to
my training in exhibition and experience design.
